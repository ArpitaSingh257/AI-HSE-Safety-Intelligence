### Then the agentic layer 🚀

If the system says **HUMAN_REVIEW_REQUIRED**, that's a perfect place to introduce an agent.

For example:

```text
                 HUMAN REVIEW
                      │
                      ▼
              Safety Intelligence Agent
                      │
              ┌───────┼────────┐
              ▼       ▼        ▼
            MCP     RAG      Internal APIs
           Tools
              │
       ┌──────┼───────────┐
       ▼      ▼           ▼
   External  Regulations  Historical
   sources   / standards  incidents
```

The agent could then **gather additional evidence using approved MCP tools**, evaluate it, and present a recommendation to the human analyst.

And yes — **the same architecture can be extended to other parts**:

* 🔎 **Investigation Agent** → gather evidence
* 📊 **Risk Analyst Agent** → investigate unusual risk patterns
* 📚 **Compliance Agent** → check applicable standards/regulations
* 🛡️ **Barrier Agent** → investigate failed barriers
* 📝 **Report Agent** → prepare investigation summaries
* 👨‍💼 **HSE Analyst Agent** → coordinate multiple specialist agents

But these should be **second-layer capabilities**, not something we add before the deterministic foundation works.
